## 一、它有什么用？优势在哪里？

蒙特卡罗（Monte Carlo）方法，简单说就是：**用大量的随机采样 + 统计，去逼近一个精确但很难直接算出来的数值。**

很多问题在数学上没有解析解，或者有解析解但算起来非常麻烦。这时候"硬算"不如"蒙着算"——只要采样足够多，统计结果就会收敛到真值。它的三大优势：

- **通用**：不依赖问题有没有解析公式，只要能把问题转成"随机试验 + 统计占比"就能套用。
- **简单直观**：核心逻辑就三个词——**撒点、判断、统计**，几乎没有门槛。
- **天然并行**：每个点是独立采样，可以放心拆分给多核/多机同时算。

生活中的例子比比皆是：金融里给期权定价、物理里模拟粒子运动、AI 里用随机采样做决策等，底层都是这一套思路。今天我把它用在一个最经典的"教学题"上——**估算圆周率 π**，并且亲手（手搓）把图形画出来。

## 二、原理与公式

### 2.1 几何模型

在**边长为 1 的正方形**里，内接一个 **1/4 圆**（半径为 1）：

- 正方形面积 = `1 × 1 = 1`
- 1/4 圆的面积 = `(π × r²) / 4 = π/4`（因为 r = 1）

所以：

```
圆面积   =  π/4
正方形面积

=  落到圆内的概率
```

### 2.2 蒙特卡罗估算

往正方形里随机撒 `N` 个点，统计落在 1/4 圆内的点数 `M`：

```
圆内占比 = M / N   ≈  π/4

⇒  估算 π = 4 × (M / N)
```

点落在圆内的判据就是**单位圆方程**：

```
x² + y² ≤ 1   （x、y 都在 [0,1) 均匀随机）
```

直观理解：撒的点越多，`M/N` 就越接近真实的 `π/4`，于是 `4 × M/N` 就越接近 π。这就是整个方法。

## 三、源码实现（手搓）

先放结论：完整的代码在 `monte_carlo_pi.py`，直接 `python monte_carlo_pi.py` 就能跑，只需提前 `pip install matplotlib`。

**我特意"手搓"的部分**：随机撒点、圆内判定、占比统计全部用 Python 原生 `random` 手写实现，**没有调用任何现成的求 π 的函数**；绘图仅借助 `matplotlib` 把结果可视化。

下面拆解关键函数。

### 3.1 核心：估算 π

```python
def estimate_pi(num_points: int) -> float:
    """用蒙特卡罗方法估算圆周率 π。
    参数：num_points (int) 撒点总数；返回：float 估算得到的 π。"""
    inside_count: int = 0            # int：记录落在 1/4 圆内的点数
    for _ in range(num_points):
        x: float = random.random()   # float：[0,1) 均匀随机横坐标
        y: float = random.random()   # float：[0,1) 均匀随机纵坐标
        if x * x + y * y <= 1.0:     # 单位圆方程：x²+y²<=1
            inside_count += 1
    ratio: float = inside_count / num_points   # float：圆内占比
    return 4.0 * ratio               # π ≈ 4 × 圆内占比
```

**逐行看**：循环里每轮生成一对 `(x, y)` 随机数，用 `x*x + y*y <= 1` 判断落在圆内；最后用 `4 * 圆内占比` 还原 π。这就是蒙特卡罗的全部核心。

### 3.2 收集数据（供画撒点图）

```python
def collect_points(num_points: int):
    """撒 num_points 个点，把圆内/圆外的点分别收集起来。
    返回：(圆内x列表, 圆内y列表, 圆外x列表, 圆外y列表)，均为 list[float]。"""
    in_x, in_y, out_x, out_y = [], [], [], []
    for _ in range(num_points):
        x: float = random.random()
        y: float = random.random()
        if x * x + y * y <= 1.0:     # 圆内
            in_x.append(x); in_y.append(y)
        else:                        # 圆外
            out_x.append(x); out_y.append(y)
    return in_x, in_y, out_x, out_y
```

把圆内、圆外的点分开收集，画图时才能用**蓝（圆内）/红（圆外）**两种颜色区分。

### 3.3 画撒点图

```python
def plot_scatter(num_points: int, save_path: str = "mc_scatter.png") -> None:
    in_x, in_y, out_x, out_y = collect_points(num_points)
    pi_est: float = 4.0 * len(in_x) / num_points      # 由本次撒点算出的 π

    fig, ax = plt.subplots(figsize=(6.2, 6.2))
    ax.scatter(in_x, in_y, s=6, c="steelblue", label="圆内")   # 蓝色：圆内
    ax.scatter(out_x, out_y, s=6, c="tomato", label="圆外")    # 红色：圆外

    # 画 1/4 圆弧：x=cosθ, y=sinθ，θ∈[0, π/2]
    theta_list = [i / 200 * (math.pi / 2) for i in range(201)]
    ax.plot([math.cos(t) for t in theta_list],
            [math.sin(t) for t in theta_list], "k-", lw=2, label="x²+y²=1")

    ax.set_aspect("equal")            # 横纵等比例，圆形才不变形
    ax.set_xlim(0, 1); ax.set_ylim(0, 1)
    ax.set_title(f"蒙特卡罗估算 π（N={num_points}，π≈{pi_est:.4f}）")
    ax.legend(); ax.grid(alpha=0.3)
    fig.tight_layout()
    fig.savefig(save_path, dpi=150)   # 保存成图片，无需弹窗
```

### 3.4 画收敛曲线

```python
def plot_convergence(max_points: int, step: int,
                     save_path: str = "mc_convergence.png") -> None:
    n_list, pi_list = [], []
    for n in range(step, max_points + 1, step):
        n_list.append(n)
        pi_list.append(estimate_pi(n))     # 重新撒 n 个点并估算

    fig, ax = plt.subplots(figsize=(7.2, 5.0))
    ax.plot(n_list, pi_list, "o-", lw=1, ms=3, label="估算 π")
    ax.axhline(math.pi, color="red", ls="--", lw=1.5, label="真实 π≈3.14159")
    ax.set_xlabel("撒点数 N"); ax.set_ylabel("估算的 π")
    ax.set_title("蒙特卡罗估算 π 的收敛性")
    ax.legend(); ax.grid(alpha=0.3)
    fig.tight_layout()
    fig.savefig(save_path, dpi=150)
```

### 3.5 主函数

```python
def main() -> None:
    pi_100k: float = estimate_pi(100_000)                # 1) 10 万点直接估算
    print(f"估算结果（10 万点）：π ≈ {pi_100k:.4f}，"
          f"误差 ≈ {abs(pi_100k - math.pi):.4f}")
    plot_scatter(5000)                                    # 2) 画 5000 点撒点图
    plot_convergence(50_000, step=1000)                   # 3) 画收敛曲线

if __name__ == "__main__":
    main()
```

**① 撒点图（N = 5000）：**
![撒点图](./mc_scatter.png)

蓝色点是落在 1/4 圆内的点，红色点是圆外的点，黑色曲线是圆边界 `x²+y²=1`。可以看到红色点"恰好"分布在圆外那一小块区域，蓝色圆内点数约占总数的 3/4——这正是 `π/4 ≈ 0.785` 的体现。图上方实时显示本次估算值 `π≈3.1288`。

**② 收敛曲线（最大 N = 50000）：**
![收敛曲线](./mc_convergence.png)

蓝色折线是估算的 π，红色虚线是真实 π≈3.14159。规律非常明显：

- **点数少时**：估算值波动很大，甚至偏离较远；
- **点数增多时**：波动幅度逐渐收窄，稳定逼近 3.14159；
- 这验证了蒙特卡罗方法的**大数定律**——采样越多，统计占比越接近真实概率。

## 五、小结与延伸

- **核心公式**：`π ≈ 4 × (圆内点数 / 总点数)`，基于正方形与 1/4 圆面积比。
- **方法论**：蒙特卡罗 = 大量随机采样 + 统计占比逼近真值，通用且直观。
- **图形**：撒点图展示"随机撒点分布"，收敛图展示"随 N 增大逼近真值"。

### 想进阶？可以试着：

1. **加快收敛**：改用**分层抽样 / 拉丁超立方**，让随机点更均匀，同点数下误差更小。
2. **提高精度**：用高维单位球/超球体积验证蒙特卡罗在高维空间的效果。
3. **省内存**：大批量点数时改用**逐点累加占比**（不用存所有点坐标），只保留最后一张收敛图。
