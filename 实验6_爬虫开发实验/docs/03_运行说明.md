# 爬虫怎么跑起来 —— 运行说明

## 一、结论先说

爬虫不是"发个链接给网站，它自己就会爬"。它是一个**跑在你电脑上的 Python 程序**，你要做的是：**把 URL 作为参数交给程序 → 程序发 HTTP 请求 → 解析 HTML → 写 CSV**。

一个 URL 就能出数据，前提是两件事成立：

1. 程序能**自动找到列表结构**（这靠 `src/crawler_core.py` 的启发式分组 + 字段正则）；
2. 页面 HTML 里**真的有数据**（纯 JS 渲染的空壳页拿不到，要走浏览器方案）。

---

## 二、三种运行形态

| 形态 | 长什么样 | 谁在用 | 本实验 |
| --- | --- | --- | --- |
| ① 脚本 + 常量 | 改代码里的 `TARGET_URL`，双击/命令行运行 | 学习者 | 需求文档 01 的写法 |
| ② 脚本 + 命令行参数 | `python run.py 基础 <URL>` | 日常最常用 | **已实现，推荐** |
| ③ 常驻服务 | Web 页面填 URL，后台跑任务 | 多人共用工具 | 超出本实验范围 |

本实验选 ②：一次写死逻辑，URL 随时换，不用改代码。

## 四、基础运行方式

```bash
# 最简：一个 URL → result.csv
.venv/Scripts/python.exe run.py 基础 https://example.com/news

# 指定输出文件
.venv/Scripts/python.exe run.py 基础 https://example.com/news -o 城市观察.csv

# 翻 3 页，每页间隔 2.5 秒（自动追加 ?page=n）
.venv/Scripts/python.exe run.py 基础 https://example.com/news --pages 3 --delay 2.5

# 启发式找错了列表？手动指定条目容器
.venv/Scripts/python.exe run.py 基础 https://example.com/news --selector "div.news-item"
```

### 终端输出怎么读

```
[页 1/1] http://.../list.html
  [✓] 200  2417 bytes  encoding=utf-8     ← 网络层通了
  可见文本 480 字 / <script> 0 个          ← 判断是不是空壳页
  候选条目块 12 个（启发式分组）            ← 找到 12 个"长得一样"的条目
  [✓] 解析 12 条，示例: 城市更新试点名单公布
成功抓取 12 条 -> result.csv               ← 落盘完成
字段缺失统计: 时间 0 条 / 作者 0 条
```

`可见文本` 少于 100 字但 `<script>` 很多 → 页面由 JS 渲染，命令行方案拿不到，转进阶任务。

## 五、URL 给进去之后，程序内部发生了什么

```
argv 取 URL
  → 建 Session（UA / Accept-Language）
  → GET，超时 10s，失败重试 3 次（2s/4s/8s）
  → 修正编码（防止 GBK 站点乱码）
  → BeautifulSoup 解析
      ├─ 路径 1：按 (标签, class) 分组，取节点数最多且带链接的一组 → 逐条抽字段
      ├─ 路径 2：条数不足 3 → 尝试从 <script> 里挖 __INITIAL_STATE__/__NUXT__ 等内联 JSON
      └─ 路径 3：仍为 0 → 打印诊断信息（可见文本、渲染建议、手动选择器用法）
  → 字段抽取：标题=最长文本节点；时间=4 组正则；作者=署名正则；链接=urljoin 补绝对
  → 按 url 去重 → 写 result.csv（utf-8-sig，列序 title,time,author,url）
```

## 六、实测记录（本地样例页，2026-11-18）

| 用例 | 输入 | 结果 |
| --- | --- | --- |
| 静态列表页 | `示例/list.html`（12 条，含相对链接与 3 种时间格式） | 12/12 条；相对链接 `detail/1004.html` 正确补全；`11-10 10:20`、`2 小时前` 保留原文 |
| 动态空壳页 | `示例/spa.html`（`<div id="app">` + 内联 state） | DOM 分组 0 条 → 内联 JSON 兜底，4/4 条 |

复现命令：

```bash
cd 示例 && python -m http.server 8899 &
cd .. && python run.py 基础 http://127.0.0.1:8899/list.html -o 示例/results/result_basic.csv
```

> 本地回环地址若被系统代理拦截，加环境变量：`NO_PROXY="*" HTTP_PROXY= HTTPS_PROXY=`。

## 七、什么时候它不管用

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `解析 0 条`，可见文本很多 | 列表不是"重复兄弟节点"结构（如表格/瀑布流） | 用 `--selector` 指定容器 |
| `解析 0 条`，可见文本极少 | JS 渲染 | 走进阶任务方案 B（Playwright） |
| 抓到的是登录页 | 需要登录态 | 不处理，换公开页 |
| 403 / 429 | 被限流 | 立即停，降频，别硬撞 |
| 中文乱码 | 编码判断失败 | 代码已 `apparent_encoding` 兜底；仍乱码则手动指定 |
| `时间` 列格式不一 | 站点本身写法混乱 | 属正常，后处理再归一 |
